# Udemy Clone

A responsive Udemy Clone website created using HTML and CSS, inspired by the Udemy online learning platform.

## Project Overview

This project is a frontend clone of the Udemy website. It was created to practice HTML structure, CSS styling, layouts, and responsive web design.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive design
- Navigation bar
- Course sections
- Course cards
- Recommended courses section
- Categories section
- Clean and simple user interface

## How to View

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

This project was created as part of my Full Stack Development learning journey to improve my frontend development skills.
